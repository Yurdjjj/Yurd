# 🎓 Yurd — AI-Powered Testing & Learning Platform

> Современная EdTech-платформа для преподавателей и учеников: создание интеллектуальных тестов с помощью ИИ за секунды, автоматическая проверка и детальная аналитика успеваемости.

---

## 📌 О проекте

**Yurd** решает главную проблему преподавателей — рутину при составлении проверочных материалов и проверке работ. С помощью генеративного ИИ учитель может за считанные секунды создать качественный, вариативный тест на любую тему или на основе загруженного учебного материала (PDF, конспект, статья).

Ученики получают удобную и честную среду для прохождения тестирования с мгновенной обратной связью и подробным разбором ошибок.

---

## ✨ Ключевые возможности

### 👨‍🏫 Для преподавателей
- **Генерация тестов с помощью ИИ:**
  - По теме, параграфу учебника или произвольному запросу.
  - По загруженным файлам (PDF, DOCX, изображения с текстом).
  - Настройка сложности (базовый, профильный, олимпиадный).
  - Разнообразие типов вопросов:
    - *Одиночный выбор (Single Choice)*
    - *Множественный выбор (Multiple Choice)*
    - *Открытый ответ (с автопроверкой через ИИ)*
    - *Установление соответствий (Matching)*
    - *Верно / Неверно (True/False)*
- **Умный редактор:** Возможность редактировать сгенерированные вопросы, менять баллы, добавлять собственные пояснения.
- **Управление классами и группами:** Назначение тестов конкретным классам, установка дедлайнов и ограничений по времени.
- **Глубокая аналитика:** Статистика по каждому ученику, распределение оценок, выявление трудных тем («узких мест» программы).
- **Банк вопросов:** Повторное использование и комбинирование вопросов из личной или общей библиотеки.

### 👨‍🎓 Для учеников
- **Интуитивный интерфейс прохождения:** Адаптивно для смартфонов, планшетов и ПК.
- **Интерактивная обратная связь:** Не просто оценка, а AI-разбор ошибок: объяснение, почему выбранный ответ неверен и как правильно мыслить при решении.
- **Личный кабинет:** История пройденных тестов, динамика прогресса и персональные рекомендации по темам для повторения.
- **Контроль честности:** Таймер на тест/вопрос, защита от случайного закрытия вкладки, перемешивание вариантов ответов.

## 🛠 Технологический стек (рекомендуемый)

| Слой | Технологии |
|---|---|
| **Frontend** | React / Next.js, TypeScript, Tailwind CSS, shadcn/ui |
| **Backend** | Python (FastAPI) или Node.js (NestJS / Next.js API Routes) |
| **Искусственный Интеллект** | Google Gemini API (Gemini 2.5 Flash / Pro) / OpenAI API, Structured Outputs (Pydantic / Zod) |
| **База данных** | PostgreSQL, Prisma ORM / SQLAlchemy |
| **Кэш и очереди** | Redis (ограничение запросов, сессии тестов, Celery / BullMQ) |
| **Аутентификация** | NextAuth.js / Supabase Auth / Clerk (роли: `teacher`, `student`, `admin`) |

## 🚀 Быстрый старт (планируемый)

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/yurd.git
cd yurd
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта по примеру `.env.example`:
```env
# База данных
DATABASE_URL="postgresql://user:password@localhost:5432/yurd_db"

# ИИ провайдер
GEMINI_API_KEY="your-gemini-api-key"

# Секреты авторизации
NEXTAUTH_SECRET="your-super-secret-key"
NEXTAUTH_URL="http://localhost:3000"
```

### 3. Установка зависимостей и запуск
```bash
# Установка пакетов
npm install

# Применение миграций БД
npx prisma migrate dev

# Запуск локального сервера разработки
npm run dev
```
